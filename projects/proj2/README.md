# Instructions

## 1. Run `python3 -m venv .venv` to create a virtual environment.
## 2. Run `source .venv/bin/activate` to source this virtual environment.
## 3. Run `pip install -r requirements.txt` to download packages (only needs dotenv to handle environment vars)
## 4. Run `bash start.sh` to execute.
## 5. `Ctrl C` once last message prints. Logs from each process are in `logs/` and results are in `output/`. 
## 6. Run my test\_output.sh or change the diff to include the `-B` flag to ignore the trailing newlines.
